# Acevedo's Barber — Barbershop Website

A dark-themed, premium website for a barbershop in Montevideo, Uruguay.

## 🔗 Live Demo
[barberia-eight-liart.vercel.app](https://barberia-eight-liart.vercel.app)

## 🛠️ Built With
- Next.js 14
- TypeScript
- Tailwind CSS

## ✨ Features
- Services section (haircut, fade, beard, eyebrows)
- Photo gallery
- WhatsApp booking integration
- Business hours and location
- Mobile responsive design

## 📁 Project Context
Freelance project for a barbershop in Montevideo, Uruguay.
